# Anthony Mazza - Interactive CV

A modern, interactive personal CV website built with HTML, CSS, and JavaScript.

## Features

- 🎨 **Modern Design** - Clean, professional layout with gradient accents
- 🌙 **Dark/Light Mode** - Toggle between themes with preference saved
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- 📄 **Print-Friendly** - Download as PDF with optimized print styles
- ✨ **Animated** - Smooth scroll animations and skill bar animations
- 🔗 **LinkedIn Integrated** - Links to your LinkedIn profile

## Live Demo

Open `index.html` in your browser or deploy to GitHub Pages.

## Customization

Edit the following sections in `index.html` to personalize your CV:

- **Experience** - Add your work history with dates, titles, companies, and descriptions
- **Education** - Add your degrees and schools
- **Skills** - Update skill names and proficiency levels (0-100%)
- **Languages** - Add languages and proficiency levels
- **Contact** - Update your email, LinkedIn, and GitHub links
- **About** - Write your professional summary

### Placeholder Markers

Look for `<!--EDIT: ...-->` comments in the HTML to find areas needing your information.

## Deployment

### GitHub Pages

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select the `main` branch as source
4. Your CV will be available at `https://yourusername.github.io/anthony-mazza-cv/`

### Local Preview

Simply open `index.html` in any modern web browser.
